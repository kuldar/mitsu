# Security

Do not post active tokens, Apple signing material, unredacted vehicle/device IDs or personal captures in a public issue. Use a repository maintainer's private security-reporting channel when one is configured. No private contact address is embedded in this template.

Treat a leaked credential as compromised: revoke/rotate with its provider and inspect Git history and distributed archives. Local ignore rules alone are not a security boundary.

This app is an experimental read-only dashboard, not a replacement for vehicle instruments or a safety system. Preserve strict diagnostic allowlists, validated routes/replies, bounded parked captures and cancellation. Remote control, coding and security/immobilizer operations are outside the current implementation. Don't publish an exploit or live actuation sequence in a routine bug report.
